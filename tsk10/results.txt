Локальная проверка TCP и UDP (macOS, netstat)

TCP-клиент:

Подключено к серверу. Введите текст (quit — выход):
Сервер: ECHO: HELLO TCP
Сервер: ECHO: QUIT

Во время открытого TCP-соединения (вывод сокращён до порта 9090):

tcp6  0  0  ::1.9090   ::1.50085  ESTABLISHED
tcp6  0  0  ::1.50085  ::1.9090   ESTABLISHED
tcp46 0  0  *.9090     *.*         LISTEN

После команды quit:

tcp46 0  0  *.9090    *.*         LISTEN
tcp6  0  0  ::1.9090  ::1.50085  TIME_WAIT

UDP-клиент:

Отправляю: Привет, UDP!
Ответ: Получено 18 байт: Привет, UDP!

Отправляю: Это датаграмма
Ответ: Получено 27 байт: Это датаграмма

Отправляю: Никаких гарантий доставки
Ответ: Получено 48 байт: Никаких гарантий доставки
